# JOCKY

JOCKY is a cross-platform forensic investigation proof-of-concept
for SIH Problem Statement 26148.

## Current Status

Phase 1 — Windows development environment setup.

## Team

- Person 1 — Windows / Team Lead
- Person 2 — Kali Linux

## Planned Pipeline

JOCKY Source
→ Lexer
→ Parser
→ AST
→ IR
→ Executor
→ Platform Adapter
→ Forensic Analysis
→ Correlation
→ Result
→ Dashboard

## Scope

Round-1 defensive forensic proof-of-concept.

The prototype does not implement antivirus bypass,
EDR disabling, kernel subversion, malware, persistence,
or offensive payloads.
